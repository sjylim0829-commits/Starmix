# 📐 Starmix Similarity Lab (스타믹스 닮음 연구소)

중학교 2학년 수학 기하 영역 **"도형의 닮음(1차시: 닮음의 뜻과 성질)"** 연구수업을 위해 개발된 인터랙티브 교육용 웹 애플리케이션입니다.

---

## 🌟 핵심 기능 및 수업 활용

### 1. 📐 2D 평면도형 닮음 랩
- **모눈 격자(Grid) 기반 작도 및 조작**: 기준 삼각형 $\triangle ABC$를 바탕으로 배율($k$)을 직접 조정.
- **오개념 타파 (왜곡 vs 정비율 확대)**:
  - `가로만 k배 늘이기`: 한쪽 방향으로만 늘렸을 때 각도가 변하고 형태가 일그러지는 것을 즉각 체감.
  - `정비율 k배 확대`: 모든 변이 동일한 비율로 늘어나며 원래 모양을 유지함을 시각화.
- **포개어보기 (Overlay) 기능**: 두 도형의 꼭짓점을 한곳에 겹쳐 각도의 불변성 직관적 확인.
- **실시간 데이터 분석**: 대응변의 비, 대응각의 크기 일치 여부, 닮음 판정 배지 제공.

### 2. 🧊 3D 입체도형 닮음 랩 (Three.js WebGL)
- **3차원 공간 자유 회전**: 마우스/터치 드래그를 통해 360도로 회전하며 직육면체, 삼각기둥, 사각뿔 관찰.
- **균일 확대 vs 단일 축 왜곡 실험**: 높이만 늘렸을 때 옆면 직사각형의 가로세로 비율이 무너짐을 확인.
- **입체도형 닮음의 본질 도출**: "입체도형이 닮았다는 것은 둘러싸고 있는 모든 면(대응면) 역시 서로 닮은 평면도형이다"라는 성질 체득.

### 3. 🎯 형성평가 도전 미션
- 1차시 핵심 성취기준을 반영한 즉석 인터랙티브 퀴즈 (3문항).
- 즉각적인 시각적 피드백과 설명 제공.

## 🚀 실행 및 배포 방법

본 프로젝트는 순수 웹 표준 기술(HTML5, CSS3, JavaScript ES6+, Three.js CDN)로 제작되어 **별도의 빌드나 서버 설치 없이 즉시 실행**할 수 있습니다.

1. **로컬 실행**: `index.html` 파일을 더블 클릭하여 크롬이나 엣지 브라우저에서 바로 실행.
2. **GitHub Pages 배포**:
   - 저장소 Settings > Pages 이동
   - Source를 `Deploy from a branch` (Branch: `main` 또는 `master`, Folder: `/ (root)`) 선택 후 저장
   - 생성된 URL을 통해 학생들의 크롬북/태블릿에서 즉시 접속 가능.
