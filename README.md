# 📐 Starmix Similarity Lab (스타믹스 닮음 연구소)

영서중학교 2학년 7반 수학 연구수업(지도교사: 임종윤, 2026. 10. 12.)을 위해 **"도형의 닮음(1차시: 닮음의 뜻과 성질)"** 교수·학습 과정안과 1:1로 매칭 개발된 인터랙티브 교육용 웹 애플리케이션입니다.

- **웹 앱 배포 주소**: [https://sjylim0829-commits.github.io/Starmix](https://sjylim0829-commits.github.io/Starmix)

---

## 🌟 핵심 기능 및 지도안 반영 사항

### 1. 📐 2D 평면도형 닮음 랩 (`js/plane-lab.js`)
- **수업 표준 기준 삼각형**: 밑변 3, 높이 4(빗변 5)인 직각삼각형 $\triangle ABC$ 채택.
- **모눈 위 직접 작도 모드**:
  - `[🔍 탐구 & 왜곡 실험]`: 배율($k$배) 조절, `가로만 2배 늘이기(왜곡)`, `정비율 2배 확대(닮음)`, `포개어보기(Overlay)` 기능.
  - `[✏️ 모눈에 직접 작도]`: 학생이 모눈 교점을 직접 클릭하여 2배 확대된 $\triangle DEF$ 작도 및 실시간 자동 검증.
- **지도 유의사항 도구 완비**:
  - `📐 각도 측정기`: 각 꼭짓점에 각도 호(Arc) 및 수치($90^\circ, 53^\circ, 37^\circ$) 시각화.
  - `📏 길이 눈금`: 변의 길이($3, 4, 5 \rightarrow 6, 8, 10$) 동적 라벨 표시.

### 2. 🧊 3D 입체도형 닮음 랩 (`js/solid-lab.js`)
- **수업 표준 직육면체 규격**: 가로 2 × 세로 3 × 높이 4.
- **3D 공간 인터랙션**: 마우스/터치 드래그로 360도 자유 회전 및 줌(Three.js WebGL).
- **지도안 실험 프리셋 탑재**:
  - `1. 전체 모서리 1.5배 균일 확대 (닮음)`
  - `2. 전체 모서리 2.0배 균일 확대 (닮음)`
  - `3. [축 분리 모드] 높이만 3배 왜곡 (비닮음)`: 앞면 직사각형($2 \times 12$)의 비율이 깨짐을 시각화하여 "대응면 역시 닮음이어야 입체도형의 닮음이 성립한다"는 개념 일반화.

### 3. 🎯 형성평가 도전 미션 (`js/missions.js`)
- **미션 1 [결손 꼭짓점 찾기]**:
  - 점 D(6, 1), E(12, 1)이 주어졌을 때 2배 닮은 삼각형이 되도록 **점 F(6, 9)의 위치를 모눈에서 직접 찾아 클릭**하는 조작형 미션 (오답 시 단계별 힌트 제공).
- **미션 2 [닮음 판정 및 닮음비 구하기]**:
  - 가로 6, 세로 4 직사각형 A vs 가로 15, 세로 10 직사각형 B의 닮음 여부 판정 및 가장 간단한 자연수의 비($m : n$) 주관식 입력 및 즉각 자동 채점.

## 🚀 실행 및 배포 방법

본 프로젝트는 순수 웹 표준 기술(HTML5, CSS3, JavaScript ES6+, Three.js CDN)로 제작되어 **별도의 빌드 과정 없이 즉시 실행** 가능합니다.

1. **로컬 실행**: `index.html` 파일을 더블 클릭하여 크롬/엣지 브라우저에서 실행.
2. **교실 기기 배포**: GitHub 저장소의 `Settings` > `Pages`에서 `main` 브랜치 배포를 활성화하여 학생들의 태블릿/크롬북에서 URL로 접속.
